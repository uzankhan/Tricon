## Development

The site uses TanStack Start, React, Tailwind CSS, and Cloudflare Workers. You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
